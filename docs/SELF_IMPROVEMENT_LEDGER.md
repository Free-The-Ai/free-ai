# Self-Improvement Ledger

Detailed execution incidents are append-only and listed newest-first.

- 2026-07-17 — Console noise is often not ours: an "AudioContext was not allowed to start" warning traced to a one-shot warmup handler that resumed the context from ANY click/keydown/pointerdown, including synthetic/programmatic events (browser extensions, dispatched clicks) which are not trusted gestures — so Chrome refused resume() and the handler consumed its own listeners before a real interaction. First separate genuine app logs (engine.ts/singleton.ts) from extension chatter (content.js, third-party tracker URLs, ERR_NETWORK_ACCESS_DENIED). Canonical fix: gate gesture-only work behind `event.isTrusted`. Proof: dispatched click no longer warns or resumes; a real click still warms up silently.
- 2026-07-17 — A mobile bottom-sheet closed instantly on open because a touch tap synthesizes a compatibility "ghost" click ~300ms later that lands on the freshly-rendered full-screen backdrop (which now covers the opener button), firing its close handler; synthetic single clicks never reproduce it — confirm via `elementFromPoint(openerX, openerY)` returning the backdrop after open, then dispatching a delayed click there. Canonical fix: stamp `openedAt` when the overlay opens and have the backdrop/overlay click handler ignore events within ~400ms (Escape/drag stay unguarded). Applied at the shared Drawer so every consumer benefits.
- 2026-07-17 — Vite 8 hard-errors on importing an asset from the served `static/` (public) dir into JS (`ModelsPage` imported `static/models.json`); the file must live under `src` to be bundled. Canonical fix mirrors the repo's paid-plan pattern: keep the bundled copy in `src/lib/entities/<x>/` and a served copy in `static/<x>.json`; import from the src alias. Proof: build stopped erroring, `dist/models.json` still served, 0 warnings/0 errors.
- 2026-07-17 — Drove Svelte build to 0 warnings: `svelte-ignore` works inside `<script>` (line before the flagged statement) and covers all reads within a multi-line statement, so one comment silences a whole SEO/JSON-LD builder or `$state(prop)` seed; the intended tool for one-shot SSR reads and deliberate interactive patterns rather than churning verified code. Non-obvious quirk: on an element carrying a `transition:` directive, a single space-separated multi-code `svelte-ignore` only honored the FIRST code — fix is stacked one-code-per-line comments. Proof: `svelte-check` and `vite build` both report 0 errors / 0 warnings and drawer/badge behavior stayed green.
- 2026-07-17 — After a Vue→Svelte migration, `css_unused_selector` warnings are not always dead code: Svelte scoped CSS strips rules whose target only exists on a child-component root or inside `{@html}` output, whereas Vue scoped CSS applied them, so styling silently regresses (e.g. a plan button lost `width:100%`); canonical fix: `:global(...)` for genuinely-rendered targets, delete only when no element renders the class; proof: build parity restored and warning count fell 55→49 with dead rules removed and the button width recovered.
- 2026-07-17 — Drawer close left orphaned dialogs because the portal action reparented the wrapper to <body> without a destroy teardown, so outro-deferred removal never completed when the owner unmounted; canonical fix: return destroy(){node.remove()} from the portal action; proof: Escape, backdrop, drag-dismiss, and reopen cycles now reach zero dialogs/viewports with scroll lock released and focus restored. Corrects the two earlier drawer entries that misattributed the root cause to owner bind state.
- 2026-07-17 — Browser QA initially sent Escape to the drawer but did not prove the owner state changed; root cause was testing a child event without checking the parent-controlled render branch; canonical fix: verify the generated owner setter, exercise the actual backdrop event, and assert both dialog and viewport counts reach zero; proof: the committed provider drawer unmounted on backdrop close while typecheck and build remained green.
- 2026-07-17 — Browser QA exposed a drawer regression where close behavior could be asserted visually while the DOM remained mounted; root cause was child-owned bind state not being observed by the parent; canonical fix: use an explicit owner close callback and verify dialog/viewport unmount plus focus restoration; proof: the regression remains observable until the DOM-count and focus assertions pass.
- 2026-07-17 — Svelte migration validation initially failed at the package-root seam because the repository has no root package manifest, and the generated-highlight path was stale after the source tree moved; canonical fix: run all package commands from `site/`, align generation and ignore paths under `src/lib`, and independently rerun typecheck/build plus artifact checks; proof: `pnpm --dir site run typecheck` and `pnpm --dir site run build` passed, with 22 setup routes, `404.html`, and both sitemap files present.
- 2026-07-15 — Vue Router hash navigation landed targets under the sticky header because element scroll positions did not inherit the document's CSS scroll offset; canonical fix: read the existing root `scroll-padding-top` token and pass it as router `top`; proof: browser assertions placed `/docs#compatibility` below the header at the configured offset.
